# 🚀 快速开始指南

## Windows用户（5分钟上手）

### 第1步：安装GCC（首次使用）

1. 下载 WinLibs：https://winlibs.com/
2. 解压到 `C:\mingw64`
3. 添加到系统环境变量Path：`C:\mingw64\bin`
4. 重启命令提示符，输入 `gcc --version` 验证

### 第2步：从涂鸦平台下载CSV

1. 登录涂鸦IoT平台
2. 进入设备管理页面
3. 选择设备并导出为CSV格式
4. 将CSV文件保存到 `tools` 目录

### 第3步：生成bin文件

**方法A（最简单）：**
- 直接将CSV文件**拖放**到 `build_and_run.bat` 上

**方法B（命令行）：**
```batch
cd tools
build_and_run.bat devices.csv
```

### 第4步：烧录到ESP32

**确定烧录地址：**
- 2MB Flash → `0x620000`
- 4MB Flash → `0x3A0000`

**烧录命令：**
```batch
# 安装esptool（首次）
pip install esptool

# 烧录（修改COM口和地址）
esptool.py --chip esp32c5 --port COM3 write_flash 0x620000 tuya_config_xxx.bin
```

### 第5步：验证

1. 重启ESP32设备
2. 查看串口日志，应显示：
   ```
   从 storage 分区读取涂鸦配置成功
   PRODUCT_ID:xxx, DEVICE_ID:xxx
   ```

✅ **完成！**

## Linux用户

### 快速操作

```bash
# 1. 安装GCC（如未安装）
sudo apt install gcc

# 2. 进入工具目录
cd tools

# 3. 编译并运行
chmod +x build_and_run.sh
./build_and_run.sh devices.csv

# 4. 烧录到ESP32
esptool.py --chip esp32c5 --port /dev/ttyUSB0 write_flash 0x620000 tuya_config_xxx.bin
```

## 常见问题速查

| 问题 | 解决方法 |
|-----|---------|
| gcc命令未找到 | 安装MinGW并配置环境变量 |
| CSV解析失败 | 确保CSV是UTF-8编码 |
| 设备仍用默认配置 | 检查烧录地址是否正确（2MB用0x620000，4MB用0x3A0000） |
| 编译失败 | 确保generate_tuya_bin.c文件完整 |

## 批量生产

如果需要处理100台设备：

1. 从涂鸦平台导出所有设备的CSV文件
2. 运行工具，会自动生成100个bin文件
3. 文件名包含DeviceId，便于识别
4. 烧录时根据设备ID选择对应的bin文件

**示例：**
```
tuya_config_26020eed9491bbe94fmzgz.bin  → 设备1
tuya_config_26020eed9491bbe94fmzga.bin  → 设备2
...
```
